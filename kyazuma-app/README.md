# Kyazuma

音楽を始めたばかりの人でも、作りたいイメージを選ぶだけで曲のタネがすぐに作れるスマホアプリ（iOS / Android）。
Expo（React Native）+ Expo Router で作っています。

## できること

### 🎹 つくる
1. **イメージを選ぶ** — 「元気・ポップ」「チル・ローファイ」「切ない・エモ」「ダーク・トラップ」「ダンス・EDM」「夏・トロピカル」から選ぶと、ドラム・ベース・コード・メロディの4小節ループが自動でできて、すぐに鳴ります。
2. **聴きながらアレンジ** — パートごとのオン/オフ、🎲 で別パターンに変更、テンポ・キーの変更、ドラムのマス目をタップしてビートを編集。再生を止めずにその場で音が変わります。
3. **保存** — 気に入ったら「マイ曲」に保存。あとから「編集」で続きを作れます。

コード進行には「王道進行」「小室進行」などの名前と、どんな雰囲気になるかの解説が付くので、使いながら音楽の基礎が自然に身につきます。

### 📁 マイ曲
保存した曲の管理。ループの再生、制作ステージ（アイデア → 作曲 → … → 完成）、BPM・キー・締め切り、タスク、歌詞、メモ。

データは端末内（AsyncStorage）に保存されます。

## しくみ

音はサンプル音源を使わず、アプリ内で合成しています（`src/music/render.ts`）。
パターン（`src/music/generate.ts`）を WAV に書き出して `expo-audio` でループ再生するので、Expo Go でもそのまま動きます。

## 動かし方

```bash
cd kyazuma-app
npm install
npm start          # QRコードを Expo Go アプリで読み取るとスマホで起動します
npm run web        # ブラウザで確認する場合
```

## 開発

```bash
npm run typecheck  # 型チェック
npm run lint       # Lint
```

## ディレクトリ構成

`kyazuma-app/` の中:

```
src/
  app/                   画面（Expo Router のルート）
    (tabs)/index.tsx     つくる（イメージから曲を生成）
    (tabs)/songs.tsx     マイ曲一覧
    song/[id].tsx        曲の詳細（ループ再生・概要・タスク・歌詞・メモ）
    new.tsx              曲の手動追加
  components/            共通コンポーネントとテーマ
  lib/                   曲データの型、ステージ定義、保存処理
  music/                 作曲エンジン
    theory.ts            音階・コードの基礎
    moods.ts             イメージごとのテンポ・コード進行・音色
    generate.ts          ドラム・ベース・コード・メロディの自動生成
    render.ts            シンセサイザー（パターン → 音声）
    useLoopPlayer.ts     ループ再生
```
